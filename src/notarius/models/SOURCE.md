# Bundled model

`segmentation-3.0.bin` is the speaker segmentation model
[pyannote/segmentation-3.0](https://huggingface.co/pyannote/segmentation-3.0)
by CNRS, released under the MIT licence (`LICENSE-segmentation-3.0.txt`).

- Revision: `e66f3d3b9eb0873085418a7b813d3b369bf160bb`
- File: `pytorch_model.bin`, renamed
- SHA-256: `da85c29829d4002daedd676e012936488234d9255e65e86dfab9bec6b1729298`

It is bundled so that Notarius users do not need a Hugging Face account:
on Hugging Face the model sits behind a form that asks for contact
details. If you use pyannote in your own work, please consider supporting
its authors through that page.
